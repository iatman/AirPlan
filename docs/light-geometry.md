# Light 几何构图

页头字标根据用户提供的 IHX 图一重新描绘轮廓，并参考图二添加正圆。字标仅用于页头，
不在首页主体重复。`circle` 的半径固定，SVG 保持等比缩放；月轮上移并包围星星，
轮廓从右上方的亮弧向左下渐隐。星星独立放在月轮内侧，字形底部保留少量暖光。

首页左图采用欧几里得《几何原本》I.1：以 A、B 为圆心、AB 为半径作两个等圆，
上交点 C 与 A、B 构成等边三角形。坐标 AB=82，C 的高度使用 82×√3/2。
参考原文：[Euclid I.1](https://math.clarku.edu/~djoyce/java/elements/bookI/propI1.html)。

中间的构图重复双圆、等边三角形与直尺辅助线，并以暖金曲线连接右侧 SQL 区域；
这是装饰构图，不作为某个数学定理的完整证明。两图均为内联 SVG，无图片、字体或脚本依赖。
手机下保留主体构图，将过渡背景淡化；暗色不显示这些元素。
