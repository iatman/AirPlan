# 风格与年份导航

## 默认风格

`config.toml`：

```toml
theme = "ihx"

[params]
colorScheme = "dark"
```

`dark` 为 IHX 墨绿暗金，`light` 为 IHX 暖灰纸色与深墨绿。配置只支持这两个值，拼写错误会在构建时报告。

访客点过页头太阳/月亮按钮后，本地选择优先。需要重新验证配置默认值时，可以使用无痕窗口，
或在浏览器控制台清除偏好并刷新：

```js
localStorage.removeItem('atman-color-scheme');
location.reload();
```

配色在加载样式前确定；按钮使用原生 JavaScript，支持键盘，主题选择可跨页面和标签页保持。
禁用本地存储时按钮仍可工作，但刷新后回到配置默认值。

RSS 仍输出标准 XML。浏览器视图加载同一段轻量主题脚本，读取本地选择、支持页内切换并跨标签页同步；没有有效本地偏好或禁用 JavaScript 时使用配置默认值。脚本只在频道的浏览器展示层中，文章全文不包含脚本，订阅器按标准 RSS 解析。

## 页头与首页的风格差异

亮色以 ihx 为主标、atman 为署名，使用暖灰纸色、深墨绿与少量暖金。字标依据提供的参考轮廓描绘，背后使用 SVG 正圆。
首页不重复字标，左侧用欧几里得 I.1 的双圆与等边三角形，中部以淡几何构图衔接 SQL 记录卡，表达观察、求知与实践。屏幕宽度不超过 800px 时隐藏 SQL 卡，并收紧首屏高度。
暗色保留开环剑线字标、江湖导航和山水首屏，表达内观、守护与行路。
两种展示由同一套 HTML/CSS 控制，切换时链接、文章列表和已有交互状态保留，导航的 I/H/X 悬停图案继续可用。

## 代码组织

主题已合并到单一本地目录 `themes/ihx/`：包含原 Even 的文章模板、基础 CSS、图标字体、翻译及资源清单。
不再依赖 `themes/even/`，同名文件以 IHX 的现有版本为准，保留原 MIT 许可与来源说明。
站点级定制仍位于项目根目录的 `layouts/`、`assets/` 和 `static/`，优先于主题。
`data/even` 和 `even.*.min.css` 是保留的历史资源名，文件均在 IHX 目录内，不是第二个主题。
常规构建只需 Hugo，不需要旧的 `node_modules`。
一个站点构建输出一套 URL，不会因切换风格生成另一套文章、重复 DOM 或重新加载 RSS。

## Archive 年份导航

右侧目录链接到 `#archive-year-2026` 等稳定锚点，支持浏览器原生锚点、返回和无 JavaScript 使用。
桌面目录在滚动时停留，较窄屏幕放到清单上方。启用 JavaScript 时，目录突出当前年份，
并随标签筛选隐藏没有文章的年份、更新文章计数。减少动画设置下使用直接跳转。

## Archive 热力图与标签页签

归档顶部增加「热力图 / 标签」两个互斥页签，每次进入默认显示热力图。
版式参考 [Chongxi 归档页](https://xice.cx/archive/) 的日历格与下划线页签，配色沿用 IHX 的亮暗变量。

- 热力图统计当前归档中的公开 Post/Look 文章，按各文章 Date 格式化后的日期汇总，不统计修改日期或虚构写作活动。
- 默认年份是最新文章所在年；下拉菜单可选已有文章的其他年份。切换年份仅更新图表，不改变下方清单的默认排序。
- 日历按周日到周六排列；UTC 日期运算用于构造格子，避开浏览器时区和夏令时偏移，闰年展示 366 天。
- 颜色分为 0、1、2、3、4 篇及以上五级；有记录的格子可悬停查看日期、篇数和标题，点击后筛选当天全部文章。
- 点击已选日期或「查看全部」可清除筛选。切换页签时清除旧筛选，防止隐藏面板中的条件继续影响清单。
- 标签筛选、文章计数和年份目录继续联动；原有文章日期降序排列保持不变。
- 手机端保留方格大小，仅在图表区域横向滚动，并显示滑动提示。
- 页签支持左右方向键、Home/End；有文章的日期可以通过键盘激活。禁用 JavaScript 时同时展示初始日历与标签链接，并保留全部清单和年份锚点。

日期通过归档条目的 `data-archive-date` 提供，与已有标签数据一起使用，无额外请求；未加载 RSS、图表库或新依赖。
实现位于 `layouts/_default/archive.html`、`layouts/partials/archive/heatmap.html`、`assets/js/archive.js`、`assets/css/archive.css`。

初始日历由 Hugo 直接渲染，脚本只负责年份切换和页面内筛选；脚本尚未加载时也有完整的日历与原生文章锚点。
CSS/JS 经 Hugo 压缩并生成内容指纹 URL 和 SRI，避免浏览器缓存旧版固定路径资源后导致新页签失效。


## Light 阅读配色（2026-10-25）

Light 页面背景从近白 `#f6f5ef` 调为暖灰 `#e6e3d9`，正文为 `#24302e`。
目录、引用和代码工具栏用较深的灰纸色，代码底色使用 `#e1dfd5`，避免长文章中出现近白亮块。
辅助文字、代码高亮和热力图同步加深；关闭 Light 顶部的背景光晕。

首页、归档、文章、About 与 RSS 浏览器视图使用一致配色；浏览器 theme-color 同步更新。
RSS 样式现在由 `assets/css/feed.css` 经 Hugo 压缩、指纹化后输出，避免固定 CSS URL 的旧缓存影响配色。
Dark 根变量不改动。已检查常用文字在页面、面板和浮层上的对比度，以及代码高亮颜色，最低约 4.64:1。
