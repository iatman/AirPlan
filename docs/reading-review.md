# 阅读体验检查（2026-10-24）

检查对象：当前 IHX 单主题，Hugo 0.110.0。使用 Chromium 自动化与截图检查，非完整 WCAG 合规审计，也未覆盖实体 iOS/Safari。

## 发现与修复

| 项目 | 检查结果 | 本次处理 |
| --- | --- | --- |
| 手机正文 | 480px 以下原为 14px / 1.95 | 调至 16px / 1.85，引用和列表继承正文；代码单独保持原字号 |
| 浅色辅助文字 | 日期对比度约 4.41:1，代码语言/版权标签约 4.10:1 | 加深辅助色，分别提高到约 5.26:1 / 4.90:1 |
| 暗色辅助文字 | 代码语言/版权标签约 4.12:1 | 提高至约 4.96:1，保留墨绿配色 |
| 代码高亮 | 字符串、注释、变量等仍使用旧浅色配色，部分对比度仅约 2.5–3.5:1 | 补全 token 分组并修正优先级，使两种风格使用各自高亮变量 |
| 代码行号 | 旧基础样式优先级较高，浅色行号仅约 1.54:1 | 修正选择器优先级；浅色约 5.41:1，暗色约 5.66:1 |
| 代码控制 ID | Set.forEach 的第二参数不是数字序号，生成多个 `code-wrap-[object HTMLDivElement]` | 转为数组迭代，生成唯一编号，aria-controls 正确对应代码块 |
| 数据表格 | 正文的 anywhere 换行规则把 pvscan、pvcreate 等命令拆开挤成窄列 | 表格恢复按单词换行、增加单元格间距，放入独立横向滚动容器 |
| 表格滚动提示 | 既无提示，也不能直接用 Tab 进入超宽表格区域 | 仅溢出时显示提示并增加焦点与名称；支持方向键，宽屏无溢出时移除额外 Tab 停靠点 |

以上对比度依据浏览器计算得到的文字颜色及纯色背景计算；不包含抗锯齿、显示器差异及背景装饰渐变影响。
普通文字的参考阈值为 4.5:1：[W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

表格仍保留 table 语义，滚动容器单独使用 region。未开启 JavaScript 时，原表格仍可横向触摸滚动，
但不会增强滚动提示及焦点。参考：[MDN overflow accessibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overflow#accessibility)。

## 验证

- 选取周记、复杂代码、表格、图片等六个代表页面；320、390、800、1440px，亮暗共 48 个组合，未发现整页横向溢出。
- 单独检查 LVM 七列表格：命令保持完整；窄屏提示可见，Tab 聚焦后方向键可滚动；宽屏自适应取消提示。
- 多代码块页面：每个按钮的 aria-controls 唯一，Enter/Space 可换行；代码区域可用方向键滚动。
- 原生目录：Enter 可展开/收起；图片预览可通过 Enter 打开、Escape 关闭，焦点返回原图片按钮。
- 进一步检查了全部 79 篇公开 Post/Look 文章在 320px 下的亮暗模式，无整页横向溢出、重复代码目标 ID 或脚本报错。
- Hugo 压缩构建通过。标签、相邻文章导航和全文 RSS 的数据不作改动。
